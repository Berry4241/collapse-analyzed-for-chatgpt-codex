# Privacy policy

**Collapse Analyzed for ChatGPT & Codex** processes your currently active browser tab locally when you click its toolbar icon or keyboard shortcut.

- **Data accessed:** the visible page structure and text near Analyzed headings, to determine which sections are expanded.
- **Data transmitted:** none by the extension. There is no telemetry, advertising, analytics, third-party API, or developer-operated server.
- **Data storage:** the extension does not use the Chrome storage API. Any temporary changes to page elements are local to the tab and reset on refresh.
- **Permissions:** `activeTab` allows temporary access to the tab the user explicitly activates; `scripting` executes the local collapse code.
- **No accounts or sign-in:** this extension has no login, service, or synchronization.

ChatGPT itself is a separate service with its own data handling practices. This privacy statement describes **only this extension**, not ChatGPT.

This is an independent project and is not affiliated with OpenAI.
