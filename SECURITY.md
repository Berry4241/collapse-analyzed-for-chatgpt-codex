# Security

Please **do not post security-sensitive vulnerabilities or authentication artifacts in public issues**.

For public-repository maintainers: enable GitHub Private Vulnerability Reporting under **Settings → Code security and analysis** if available. If this has not yet been enabled, do not include exploit details or secrets in an issue; request a private contact method from the maintainer.

Never send ChatGPT cookies, access tokens, API keys, or your complete private conversation history while reporting a bug.
